# 性能回归验证

两个 Frida 脚本仅用于开发验证，不随安装包发布。按 jail 工作流启动选定设备的 Frida 后执行，测试完成后停止服务。

```sh
frida -H 192.168.31.159:2909 -n SpringBoard -q -t 8 -l worker/verify_idle.js
frida -H 192.168.31.159:2909 -n SpringBoard -q -t 8 -l worker/verify_lifecycle.js
```

- `verify_idle.js` 只读取开关、捕获状态和已有窗口。刚加载插件、开启仅录屏显示、没有录屏且没有控制中心强制显示时，预期 `windows: []`。经历录屏后允许复用一个停用的隐藏窗口，但应无触点和轨迹控制器。
- `verify_lifecycle.js` 创建隐藏的隔离窗口，将测试事件直接交给插件，不向系统分发触摸、不修改用户偏好。检查停用不记录触摸、抬手清除活动触点、停用清空动画/轨迹界面/方向观察/延迟清理、再次启用恢复效果。预期 `lifecycle: passed`。
- 上述检查验证资源生命周期，不替代真实录屏、多指手势、续航和视觉体验测试。

## 待用户验收

共同前置：总开关与“仅录屏显示”开启，控制中心没有手动强制显示。

| 目标 | 操作 | 预期 |
| --- | --- | --- |
| 未录屏不干扰触摸 | 不录屏，连续滚动列表、键盘输入、多指缩放 | 不显示触点，不影响系统手势；主观流畅度正常 |
| 录屏启停恢复 | 打开拖尾、轨迹、形变，连续开始/停止录屏两轮 | 录屏时效果正常；停录立即消失；再次录屏恢复全部效果 |
| 中途停用清理 | 录屏时拖动或长按，再停止录屏或关闭总开关 | 无残留触点、轨迹或持续动画；重新开启后无旧触点 |
| 多指与旋转 | 录屏中多指移动并交错抬手，切换横竖屏，测试图片自动旋转 | 各触点独立回收，轨迹位置与图片方向正常 |
| 设置与覆盖 | 切换两张自定义图片及黑白颜色；操作控制中心临时显示开关后返回设置 | 图片及时更新，无错误缓存或崩溃；提示随开关变化 |
| 设置包精简后的导航 | 打开设置页，滚动到页尾再回到顶部，退出后重新进入 | 列表、导航栏和返回操作正常，无卡住或崩溃 |
| 设置包精简后的选择器 | 在设置中选择表情、导入图片，再调整颜色和大小，退出后重新进入 | 选择器正常打开，配置及时保存并恢复 |
| 续航 | 保持仅录屏模式且不录屏，按相近日常使用条件观察耗电 | 无由插件持续轮询或动画引起的额外耗电；实际续航需用户长期观察 |
